## 🔄 How It Works

### Work Desktop:
```
docker-compose.yml (port 5432)
         ↓
backend/.env (port 5432)
         ↓
✅ Everything uses port 5432
```

### Personal Laptop:
```
docker-compose.yml (port 5432)
         ↓
docker-compose.override.yml (port 5433) ← OVERRIDES
         ↓
backend/.env (port 5432)
         ↓
backend/.env.local (port 5433) ← OVERRIDES
         ↓
✅ Everything uses port 5433
```
